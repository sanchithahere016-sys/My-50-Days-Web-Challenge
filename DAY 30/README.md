# 🚀 Day 30 - Full CRUD Operations (PUT & DELETE Requests)

## 📌 Project Overview

Day 30 completes the CRUD (Create, Read, Update, Delete) cycle by implementing **PUT** and **DELETE** HTTP requests using the Fetch API and the JSONPlaceholder REST API.

Users can:
- Submit a proposal (POST)
- Update an existing proposal (PUT)
- Delete a proposal (DELETE)

This project demonstrates how modern web applications interact with REST APIs to modify and remove data.

---

## ✨ Features

- 📝 Submit a new proposal
- ✏️ Update an existing proposal using a PUT request
- 🗑️ Delete a proposal using a DELETE request
- ⚠️ Confirmation dialog before deleting
- 📡 Fetch API with async/await
- 🔄 JSONPlaceholder REST API integration

## ⚙️ How It Works

### ➜ Create (POST)
Users submit a proposal through the form. The proposal is sent to the API using a POST request.

### ➜ Update (PUT)
Clicking **Update Proposal** sends a PUT request to update the selected proposal.

### ➜ Delete (DELETE)
Clicking **Delete Proposal** opens a confirmation dialog. After confirmation, a DELETE request is sent to remove the proposal.
