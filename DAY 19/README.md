# Day 19 – Event Delegation & Dynamic Modals

## 📌 Overview

Day 19 introduces **Event Delegation** and **Dynamic Modals**, two essential JavaScript concepts used in modern web applications. Instead of attaching event listeners to every button individually, a single event listener is attached to the parent container, making the application more efficient and scalable.

---

## 🚀 Features

- Dynamically generated initiative cards
- "View Details" button for each initiative
- Event Delegation using a single event listener
- Dynamic modal displaying project information
- Close modal using:
  - Close (×) button
  - Clicking outside the modal
  - Escape key
- Responsive modal design
- Dark mode compatibility
