# 📅 Day 16 - LocalStorage & Client-Side Data Persistence

## Objective
Implement browser LocalStorage to automatically save form data and restore it after a page refresh.

## Features
- Auto-save Name and Email while typing
- Restore saved data on page reload
- Store data using LocalStorage
- Convert objects using JSON.stringify() and JSON.parse()
- Clear stored data after successful form submission

## Technologies Used
- HTML5
- CSS3
- Vanilla JavaScript
- LocalStorage API

## Learning Outcomes
- Browser Storage
- LocalStorage API
- JSON Serialization
- JSON Parsing
- Client-side Data Persistence
- State Recovery
