# 📅 Day 18 – Timers, Intervals & The Event Loop (Dynamic Carousel)

## 📌 Overview

Day 18 focuses on using JavaScript timers and the Event Loop to build an auto-rotating testimonial carousel. The carousel automatically updates the displayed testimonial every few seconds using `setInterval()`, demonstrating how JavaScript handles asynchronous tasks.

---

## 🎯 Objectives

- Understand the JavaScript Event Loop.
- Learn how `setInterval()` works.
- Display dynamic content using arrays.
- Update the DOM automatically at fixed intervals.
- Track application state using an index variable.

## 🚀 How It Works

1. Testimonial data is stored in a JavaScript array.
2. The first testimonial is displayed when the page loads.
3. Every 3 seconds, JavaScript updates:
   - Member name
   - Member quote
4. After the last testimonial, the carousel returns to the first testimonial and repeats continuously.
