# 📅 Day 14 – Dynamic DOM Rendering (Data vs. View)

## 📖 Overview
Day 14 focuses on separating data from the user interface by dynamically generating HTML using JavaScript. Instead of manually writing each project card in HTML, project information is stored in JavaScript objects and rendered into the DOM using loops and template literals.

## 🎯 Objectives
- Understand the difference between data and view.
- Store project information using Arrays and Objects.
- Generate HTML dynamically using JavaScript.
- Practice DOM manipulation with `innerHTML`.
- Use template literals for cleaner HTML generation.
- Apply conditional rendering using CSS classes.

## 🛠️ Technologies Used
- HTML5
- CSS3
- Vanilla JavaScript

## ✨ Features

## 🚀 How It Works
1. Project details are stored in a JavaScript array.
2. The initiatives container is selected using `getElementById()`.
3. The `forEach()` loop iterates through each project.
4. Template literals generate the HTML structure.
5. The generated cards are inserted into the page using `innerHTML`.
6. Cards receive different border colors depending on their status.
