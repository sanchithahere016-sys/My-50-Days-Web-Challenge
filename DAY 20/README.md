# 📌 Day 20 – Stateful Task Tracker

## 📖 Project Overview

The **Stateful Task Tracker** is a dynamic task management application built using **HTML, CSS, and Vanilla JavaScript**. The project demonstrates how to manage application state using JavaScript arrays while implementing complete CRUD (Create, Read, Update, Delete) operations. The interface automatically updates whenever the state changes, providing a smooth and interactive user experience.

- ➕ Add new tasks
- 📋 Display tasks dynamically

## ⚙️ How It Works

1. Type a task into the input field.
2. Click the **Add Task** button.
3. The task is stored inside the `taskState` array.
4. The `renderTasks()` function updates the UI.
5. Click the checkbox to mark a task as completed.
6. Click the **×** button to remove a task.
7. *(Bonus)* Tasks are stored in Local Storage and remain after refreshing the page.
