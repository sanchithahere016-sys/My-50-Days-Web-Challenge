# Day 13 - Client-Side Form Validation

## Objective
Build a membership form with JavaScript validation.

## Features
- Prevent form submission
- Validate Full Name
- Validate Email Address
- Display validation messages
- Clear form after successful submission

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Learning Outcomes
- DOM Selection
- Event Listeners
- preventDefault()
- Conditional Statements
- Form Validation
