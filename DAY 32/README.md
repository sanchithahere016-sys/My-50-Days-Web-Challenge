# 📅 Day 32: Architecture & Code Splitting (ES6 Modules)

## 🎯 Objective

The goal of Day 32 is to refactor the Synexus Community application into a modular JavaScript architecture using native ES6 Modules.

Instead of keeping all JavaScript code in one large file, the application is divided into separate files for utility functions, API operations, and main application logic.

## 🛠️ Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript (ES6)
- ES6 Modules
- Import / Export
- Fetch API
- GitHub API
- JSONPlaceholder API
