# 📅 Day 12 - Mobile Menu Toggle

## 📖 Overview
Day 12 focuses on adding interactivity to the Synexus Community website using JavaScript. A responsive mobile navigation menu is implemented, allowing users to open and close the navigation links with a hamburger menu on smaller screens.

## 🎯 Objective
- Learn basic JavaScript DOM manipulation.
- Implement a responsive mobile navigation menu.
- Toggle CSS classes dynamically using JavaScript.
- Improve user experience on mobile devices.

## 🛠️ Technologies Used
- HTML5
- CSS3
- Vanilla JavaScript

## ✨ Features
- Responsive navigation bar
- Hamburger menu for mobile devices
- Dynamic menu toggle using JavaScript
- Mobile-friendly layout
- Accessible navigation button with `aria-label`

## 📂 Project Structure
```
Day-12-Mobile-Menu-Toggle/
│── index.html
│── style.css
│── script.js
└── README.md
```

## 📚 Key Concepts Learned
- DOM Selection using `querySelector()`
- Event Listeners
- `classList.toggle()`
- Responsive Web Design
- Mobile Navigation

## 🚀 Outcome
Successfully created a responsive navigation menu that dynamically opens and closes on mobile devices using HTML, CSS, and JavaScript.
