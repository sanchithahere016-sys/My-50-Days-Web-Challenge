# 📅 Day 15 – Array Filtering & Real-Time Search

## 📌 Overview
Day 15 focuses on manipulating JavaScript arrays by implementing a real-time search feature. The project dynamically filters initiative cards based on the user's input and instantly updates the displayed results.

---

## 🚀 Features
- 🔍 Real-time search functionality
- ⚡ Dynamic rendering of initiative cards
- 🧹 Reusable rendering function
- 📂 Array filtering using `.filter()`
- 🔤 Case-insensitive search with `.toLowerCase()` and `.includes()`
- 📭 "No Results Found" message when no matches exist
- 📱 Responsive and user-friendly interface

---

## 🎯 How It Works
1. The page loads and displays all initiatives.
2. Users type into the search box.
3. JavaScript filters the project data in real time.
4. Matching initiative cards are displayed instantly.
5. If no matches are found, a "No initiatives match your search." message is shown.

---

## 💻 Output
- Displays all initiative cards on page load.
- Filters cards instantly as the user types.
- Shows a "No Results Found" message when there are no matching initiatives.
