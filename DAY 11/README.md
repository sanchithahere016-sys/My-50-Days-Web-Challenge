# 📅 Day 11 – JavaScript Engine & DOM Fundamentals

## 📖 Overview
Day 11 introduces JavaScript and the Document Object Model (DOM). The goal is to make the web page interactive by connecting JavaScript to the HTML document, selecting elements, and responding to user actions.

## 🎯 Objectives
- Link a JavaScript file using the `defer` attribute.
- Select HTML elements with `querySelector()`.
- Handle user interactions using `addEventListener()`.
- Update page content dynamically with `textContent`.
- (Bonus) Toggle a CSS class using `classList.toggle()`.

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript (ES6)

## ✨ Features
- Connected JavaScript to the webpage.
- Selected the hero heading and button.
- Added a click event listener.
- Changed the hero heading text when the button is clicked.
- Bonus: Toggled the heading color using a CSS class.
